# cpp-yandex-practicum-QtCalculator-sprint2
Решение финальной задачи 2-го спринта, курса яндекс практикум "С++ расширенный"

Задание:
Возьмите заготовку из папки sprint3/template-calculator вашего репозитория.
В финальный вариант калькулятора добавим поддержку разных типов данных. С этим помогут шаблоны.
Проект будет состоять из трёх частей:
Интерфейс калькулятора (класс MainWindow).
Калькулятор, реализующий арифметические операции (класс Calculator).
Контроллер для взаимодействия интерфейса и калькулятора (класс Controller).
Контроллер уже полностью реализован в заготовке, вам не нужно его изменять. Ваша задача — реализовать MainWindow и Calculator.
Контроллер и калькулятор — шаблонные классы. Они работают с числами определённого типа.
Главное окно (объект MainWindow) можно подключать к разным контроллерам, при этом будет меняться тип чисел в калькуляторе. При подключении к главному окну контроллер передаёт ему функции обратного вызова, которые следует вызывать, когда пользователь нажимает кнопки калькулятора.
Калькулятор будет поддерживать следующие типы чисел:
double,
float,
uint8_t,
int,
int64_t,
size_t,
Rational.
Для поддержки дробных чисел используйте своё решение последней задачи темы «Перегрузка операций».
Что нужно сделать
Подключите к проекту вашу реализацию класса Rational и используйте её для вычисления арифметических операций с дробями.
Внесите изменения в класс Calculator:
Преобразуйте класс Calculator в шаблонный. Шаблонный параметр — тип чисел, которыми оперирует калькулятор.
Измените тип возвращаемого значения методов вычисления (Add, Sub, Div, Mul, Pow). Они должны возвращать std::optional<Error>. Тип Error определите как псевдоним std::string. Если вычисление удалось, метод должен вернуть std::nullopt. В противном случае нужно вернуть текст ошибки. Они перечислены ниже.
Преобразуйте тип для сохранения числа в память (mem_ ) в std::optional<Number>, что позволит убрать из класса поле для проверки наличия записи в памяти — bool has_mem_.
Возведение в степень для целых и дробных чисел различается — добавьте функции для реализации вычислений.
Вот ошибки, которые должен возвращать калькулятор:
Для целых чисел (int, uint8_t, size_t, int64_t) и Rational при делении на ноль нужно вывести ошибку Division by zero.
Также для целых и дробных чисел при возведении 0 в степень 0 нужно выдать ошибку Zero power to zero.
При возведении дробного числа в степень другого дробного нужно выдать ошибку Fractional power is not supported, если знаменатель степени не равен 1.
При возведении целого числа в степень нужно выдать ошибку Integer negative power, если степень отрицательна. Числа Rational можно возводить в отрицательную степень.
Методы Mul, Add, Sub никогда не возвращают ошибку, тем не менее тип возвращаемого значения всё равно должен быть std::optional<Error>. Деление и возведение в степень всегда успешны для чисел float и double, поскольку эти типы содержат значение NaN.
Функция pow из стандартной библиотеки подходит для возведения в степень только чисел с плавающей точкой (float, double). В файле pow.h вы найдёте эффективную реализацию возведения в степень для целых чисел и Rational. Реализуйте шаблонную версию метода возведения в степень — в зависимости от типа данных должна быть вызвана нужная функция возведения в степень.
Рассмотрим класс MainWindow. Рекомендуется оставить только интерфейс, а код переделать полностью. Теперь класс MainWindow отвечает только за отображение данных и вызов колбэк-функций при событиях, связанных с действиями пользователя.
Начнём с интерфейса. В него нужно внести две правки:
Добавить элемент cmb_controller типа QComboBox со следующими текстовыми значениями:
double,
float,
uint8_t,
int,
int64_t,
size_t,
Rational.
Заменить кнопку «Запятая» (tb_comma) на экстра-кнопку tb_extra, надпись на которой может меняться в зависимости от типа чисел (за изменение кнопки отвечает контроллер).
В самом классе нужно реализовать методы для изменения текста, методы для установки колбэк-функций и обработчики сигналов.
Вот методы для изменения текста:
void SetInputText(const std::string& text) — устанавливает вводимое число или результат вычисления в ui->l_result.
void SetErrorText(const std::string& text) — устанавливает текст ошибки (подробности об отображении ошибки ниже) в ui->l_result.
void SetFormulaText(const std::string& text) — устанавливает текст формулы, отображаемой над вводом числа в ui->l_formula.
void SetMemText(const std::string& text) — устанавливает индикатор памяти ui->l_memory.
void SetExtraKey(const std::optional<std::string>& key) — устанавливает текст экстра-кнопки. Если передано nullopt, то нужно скрыть экстра-кнопку.
Ошибка отображается в том же поле, что и вводимое число, но нужно установить красный шрифт таким способом: ui->l_result->setStyleSheet("color: red;"). Когда вызывается метод SetInputText, нужно восстановить цвет текста, вызвав ui->l_result->setStyleSheet("").
Далее рассмотрим публичные методы для установки колбэк-функций. Эти методы принимают функциональный объект и сохраняют его в переменную класса, чтобы потом вызвать колбэк-функцию при определённом событии.
void SetDigitKeyCallback(std::function<void(int key)> cb) — колбэк-функцию нужно вызывать при нажатии кнопки с цифрами от 0 до 9.
void SetProcessOperationKeyCallback(std::function<void(Operation key)> cb) — колбэк-функцию нужно вызывать при нажатии кнопки операции (сложение, вычитание, умножение, деление, возведение в степень).
void SetProcessControlKeyCallback(std::function<void(ControlKey key)> cb) — колбэк-функцию нужно вызывать при нажатии других кнопок. Они перечислены в типе ControlKey в enums.h.
void SetControllerCallback(std::function<void(ControllerType controller)> cb) — колбэк-функцию нужно вызывать при изменении типа чисел.
Обработчики сигналов, которые вам нужно реализовать, реагируют на все кнопки в интерфейсе и изменение типа чисел (cmb_controller). В этих случаях нужно вызвать соответствующую функцию обратного вызова, установленную одним из вышеперечисленных методов.
Ограничения
При проверке типа чисел используйте if constexpr.
